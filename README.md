# 2026 数学建模 C 题工作区

本目录是当前项目工作区。赛题为 2026 年高教社杯全国大学生数学建模竞赛 C 题《微网与外部电网电力调控策略》。当前已完成问题一至问题四的求解、结果分析与模型检验；问题二及问题四日前分支采用动态净负荷分位数，问题二至问题四统一使用含二元互斥的混合整数模型。本项目交付边界止于论文撰写前，不维护论文主稿。

## 当前有效产物

- `C题.pdf`、`附件.zip`、`附件/`：题目与唯一原始数据副本。
- `problem1_solve.py`：问题一可复现求解与出图入口。
- `q234_solve.py`：问题二至问题四正式求解入口。
- `results/`：问题一至问题四结果表、摘要、统计与复现清单。
- `figures/`：各问原始数据图、过程图、结果图及灰度质检图。
- `docs/`、`问题1_求解说明.md`、`问题2至4_求解说明.md`：模型与结果说明。
- `working/`、`outputs/`：数据预处理脚本、中间数据与汇总工作簿。
- `数模要求/`：2026 年论文格式与 AI 使用规范。
- `archive/废弃文件_论文撰写阶段/`：不属于当前交付范围的主稿、旧论文草稿和旧版自查文件。

## 复现问题一

```powershell
python -m pip install -r requirements-problem1.txt
python problem1_solve.py --smoke
python problem1_solve.py
```

程序从 `附件/附件1.xlsx` 读取数据，从 `附件/附件5/result1.xlsx` 读取官方模板，输出到 `results/` 与 `figures/`，不会覆盖原始附件。

## AI 接续顺序

1. 阅读 `使用指南.md`、`项目记忆.md`、`C题.pdf` 和当届官方规范。
2. 核验问题一的复现清单、结果与独立 P2 门禁状态。
3. 复核问题二至四的动态净负荷分位数、滚动调整触发门槛和问题四电价信息边界。
4. 论文撰写由项目外后续流程负责，不使用 `archive/废弃文件_论文撰写阶段/` 中的材料作为当前成果。

本项目中的 AI 生成内容均为学习与研究草稿，提交前必须由参赛队伍人工核验和改写。
